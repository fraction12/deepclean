# Quickstart

## Install

```bash
npm install -g @fraction12/deepclean
deepclean --version
deepclean doctor
```

For a one-off run:

```bash
npx @fraction12/deepclean@latest doctor
```

## Run the read-only loop

From the target repository root:

```bash
deepclean init
deepclean doctor
deepclean scan
deepclean report
deepclean status
deepclean next
```

`scan` collects local evidence first and runs Codex synthesis by default. Use evidence-only mode when no provider execution should happen:

```bash
deepclean scan --evidence-only --json
deepclean report
```

## Inspect one item

```bash
deepclean show candidate-001
deepclean explain candidate-001
deepclean plan candidate-001
deepclean handoff candidate-001 --format codex
```

Treat `report` and `next` as recommendations to inspect. They are not permission to rewrite the repo.

## Work from the campaign queue

Use `campaign` when you want the current cleanup work grouped into PR-sized opportunities:

```bash
deepclean campaign
deepclean campaign --json
deepclean plan opportunity-001
deepclean handoff opportunity-001 --format codex
```

Opportunities can be safe-agent, auto-fixable, design-needed, blocked, or stop-campaign. Only auto-fixable targets can enter guarded fix/work execution.

## Review a pull request

```bash
deepclean review-pr --base origin/main --head HEAD --json --state-dir .octocheck/deepclean
```

Deepclean emits source-safe PR context for review agents. OctoCheck should own GitHub publishing; Deepclean supplies the local evidence, related findings, risk summary, verification suggestions, and prompt context.

## Return to a repo

Use `status` first:

```bash
deepclean status --json
```

It reports current runs, reports, queue state, stale artifacts, locks, pending revalidation, and the recommended next command.
