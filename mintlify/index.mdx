# Deepclean

Deepclean scans working-but-sloppy repositories, gathers local evidence, and writes source-safe cleanup reports, PR-sized opportunities, plans, and handoffs under `.deepclean/`.

It is built for codebases that already run, but need clearer boundaries, less duplication, safer refactors, stronger tests, and better sequencing.

AI-generated repos are the core use case: projects that shipped quickly with agent help and now need a cleanup queue that a developer can trust.

## What Deepclean does

- Builds local evidence from file structure, imports, tests, duplication, churn, SARIF, duplicate-detection output, and language-specific shape.
- Produces durable findings, candidates, cleanup themes, PR-sized opportunities, reports, plans, handoffs, and lifecycle records under `.deepclean/`.
- Runs local evidence first, then Codex synthesis by default unless `--evidence-only`, `--offline`, or `--local-only` is used.
- Keeps recommendations separate from source edits unless an explicit guarded fix or work lane is used.
- Gives agents a narrow, proof-backed next step instead of a broad rewrite brief.

## First command

```bash
npm install -g @fraction12/deepclean
deepclean doctor
```

Then follow the [quickstart](/quickstart).

## Copy-paste agent prompt

Give this to Codex, Claude Code, Cursor, or any repo-aware coding agent when you want it to install Deepclean and get a repo started:

```text
Install and set up Deepclean for this repository.

Work from the repo root. First check that Node.js is version 22 or newer and that npm and git are available. Install or update the Deepclean CLI with:

npm install -g @fraction12/deepclean

Then run:

deepclean --version
deepclean doctor
deepclean init

Make sure `.deepclean/` is in `.gitignore` unless this repo intentionally commits Deepclean state. Run the first report-first pass:

deepclean scan --json
deepclean report --latest
deepclean campaign --json

Summarize what Deepclean found, where it wrote state, and the safest next PR-sized cleanup opportunity. Do not edit source files or run `deepclean fix` unless I explicitly ask you to continue.
```
