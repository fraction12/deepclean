# CLAUDE.md

This repo includes a project skill for using DeepClean correctly:

- `skills/deepclean/SKILL.md`

Use that skill whenever a task asks to run DeepClean, inspect repo cleanup state, run quality gates, select cleanup opportunities, create plans/handoffs, review PRs, or apply guarded cleanup fixes.

DeepClean is report-first and source-safe by default. Source mutation is only allowed through an explicit guarded fix request with verification evidence.
