## Why

Deepclean has moved past its public-alpha positioning, but the public site still labels the product as alpha. The landing page should describe the current released state so visitors do not see stale launch status.

## What Changes

- Remove public-alpha wording from the landing page without adding a replacement status badge.
- Update the install snippet to use the current default `deepclean scan` path.
- Keep the existing layout, branding, install target, and GitHub links unchanged.

## Capabilities

### New Capabilities

- `public-release-status`: Public landing-site launch/status wording for the released Deepclean CLI.

### Modified Capabilities

- None.

## Impact

- Updates static site copy in `site/index.html`.
- Does not change CLI behavior, package publishing, generated artifacts, or release automation.
