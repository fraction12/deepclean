## ADDED Requirements

### Requirement: Broad candidate decomposition
The system SHALL decompose broad maintainability candidates into deterministic PR-sized child candidates before guarded fix execution.

#### Scenario: Large function is split
- **WHEN** an agent runs `deepclean split candidate-004 --json` for a large-function parent
- **THEN** Deepclean writes multiple child candidates with parent linkage, sequence metadata, bounded file ranges, and the original evidence trail

#### Scenario: Candidate is already bounded
- **WHEN** an agent runs `deepclean split candidate-003 --json` for a candidate that is already PR-sized
- **THEN** Deepclean refuses with a structured diagnostic and does not mutate candidate state

### Requirement: Deterministic split strategies
The system SHALL choose deterministic split strategies for large functions, large files, dependency hotspots, and shallow-wrapper clusters.

#### Scenario: Shallow wrapper cluster is split
- **WHEN** a candidate is backed by shallow-wrapper cluster evidence
- **THEN** Deepclean creates child candidates that group wrapper spans into bounded same-file slices

#### Scenario: Dependency hotspot is split
- **WHEN** a candidate is backed by dependency-hotspot evidence
- **THEN** Deepclean creates separate child candidates for incoming and outgoing dependency pressure

### Requirement: Parent candidate supersession
The system SHALL mark a split parent candidate as superseded by its child candidates without claiming the underlying smell is fixed.

#### Scenario: Split succeeds
- **WHEN** `deepclean split candidate-004` writes child candidates
- **THEN** the parent candidate records child candidate IDs, has status `superseded`, and remains traceable through findings and lifecycle events

### Requirement: Child candidate fix readiness
The system SHALL treat child candidates generated by decomposition as approved bounded slices.

#### Scenario: Child candidate is targeted by work
- **WHEN** an agent runs `deepclean work <child-candidate> --mode guarded --apply --verification "npm test" --json`
- **THEN** Deepclean applies normal scope, verification, revalidation, and PR gates to the child without refusing it as the original broad parent
