## Why

Cleeby gives Deepclean a friendlier identity than the current futuristic landing page. The public site should match that mascot: cute, direct, low-noise, and focused on what the tool does and how to install it.

## What Changes

- Replace the dark animated constellation-style site with a simple mascot-led landing page.
- Reduce content to the essentials: tool name, what it does, install command, links, and workflow.
- Remove the constellation canvas script from the page runtime.
- Keep Cleeby as the primary visual asset and keep the existing favicon/social metadata.

## Capabilities

### New Capabilities

- `cleeby-website`: Mascot-led public website presentation for Deepclean.

### Modified Capabilities

- None.

## Impact

- Updates static site files under `site/`.
- Leaves CLI behavior, package publishing, GitHub Pages deployment, and generated Deepclean artifacts unchanged.
