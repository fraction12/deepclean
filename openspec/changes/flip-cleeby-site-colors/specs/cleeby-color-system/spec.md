## ADDED Requirements

### Requirement: Mascot-aligned color system
The public website SHALL use a color system derived from Cleeby's dark navy, aqua, amber, and mint palette.

#### Scenario: Visitor opens the site
- **WHEN** a visitor opens the site
- **THEN** the page presents a dark navy surface with aqua, amber, and mint accents instead of a generic pale background

### Requirement: Low-noise cute presentation
The public website SHALL keep the simplified no-fluff layout while changing the palette.

#### Scenario: Page renders
- **WHEN** the page renders
- **THEN** the design remains static, readable, and free of background grids, constellation effects, or busy futuristic decoration

#### Scenario: Page renders on mobile
- **WHEN** the page renders on a narrow viewport
- **THEN** text, links, install commands, and workflow items remain readable without overlap or horizontal scrolling
