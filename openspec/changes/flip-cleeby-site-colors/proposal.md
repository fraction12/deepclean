## Why

The simplified Cleeby site is structurally right, but the pale website palette feels generic next to the mascot. The site should borrow more directly from Cleeby's navy, aqua, amber, and mint colors.

## What Changes

- Flip the site from a pale utility palette to a Cleeby-colored dark navy surface.
- Keep the page simple, cute, and low-noise with no background grid or futuristic animation.
- Preserve the existing content structure, links, install snippet, and workflow.

## Capabilities

### New Capabilities

- `cleeby-color-system`: Mascot-aligned website color system for the public site.

### Modified Capabilities

- None.

## Impact

- Updates `site/styles.css` and page color-scheme metadata.
- Does not change CLI behavior, build workflow behavior, or generated Deepclean artifacts.
