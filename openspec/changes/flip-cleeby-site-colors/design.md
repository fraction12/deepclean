## Context

Cleeby's logo already has the right visual personality: dark navy background, bright aqua body, amber light, and mint detail. The current site uses a light blue-white surface that feels more generic than the mascot.

## Goals / Non-Goals

**Goals:**

- Make the website feel like it belongs to Cleeby.
- Keep the no-fluff page structure and copy unchanged.
- Preserve clear contrast and mobile readability.

**Non-Goals:**

- Add new artwork, animation, or layout sections.
- Reintroduce the old futuristic constellation style.
- Change README, npm package, or CLI behavior.

## Decisions

- Use a deep navy page background and darker panels, with aqua text accents and amber/mint interactive highlights.
- Make the primary install button amber to feel warmer and cuter than a standard dark CTA.
- Keep cards/panels simple with thick rounded borders and small offset shadows rather than glows or decorative effects.

## Risks / Trade-offs

- [Risk] Dark UI can become too serious again. -> Mitigation: use warm amber buttons, rounded surfaces, and Cleeby-forward accents rather than neon gradients or animation.
