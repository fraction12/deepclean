## Why

The public site has the right simple Cleeby-led structure, and the new launch video gives visitors a quick product feel without adding more copy. The site should include the video as a focused media section while preserving the no-fluff layout.

## What Changes

- Add the Deepclean launch MP4 and poster image to the site assets.
- Add a single "Watch" section between the hero and install sections.
- Update the static site build and local preview server so MP4/JPEG assets are served correctly.

## Capabilities

### New Capabilities

- `site-launch-video`: Public site launch video presentation.

### Modified Capabilities

- None.

## Impact

- Updates only static website files, site asset handling, and OpenSpec documentation.
- Does not change CLI behavior, package publishing, or generated Deepclean artifacts.
