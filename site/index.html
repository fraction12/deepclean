Deepclean for fast‑moving AI‑assisted repos.

Scan a local codebase, find the structural work that matters, and turn it into reviewable reports, plans, and agent-ready handoffs.

$ npm install -g @fraction12/deepclean GitHub

Local evidence first. No source edits. Built for one focused improvement at a time.

Scan Map Rank Handoff

Workflow

From repo signals to the next clear move.

01

Scan

Collect local graph, churn, duplication, tests, and file evidence.

02

Map

Group files into semantic features so the report has product-shaped context.

03

Rank

Group findings by impact, confidence, effort, and blast radius.

04

Handoff

Write bounded plans an agent can execute without disturbing the rest of the repo.

Install

Try it in a local repo.

Generated artifacts stay under .deepclean/ so the evidence trail survives the agent run. 

npm install -g @fraction12/deepclean
deepclean init
deepclean scan --synthesize
deepclean report
deepclean next
