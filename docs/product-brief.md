# Product Brief

## Problem

AI-assisted coding can get a project functional quickly while leaving behind shallow modules, repeated logic, tangled imports, overlong functions, weak tests, and unclear domain language.

## Goal

Build a CLI that reviews a local repo, produces durable cleanup candidates, and helps apply/recheck one improvement at a time.

## Initial Reviewer Lanes

- Architecture/deepening opportunities
- Duplication and repeated concepts
- Complexity and long functions
- Testability gaps
- Dependency and import tangles
- Dead code and unused exports
- Naming and domain language drift

## Non-Goals For The First Pass

- No autonomous repo-wide rewrite.
- No public upload of private source.
- No automatic commits, pushes, or PRs.
- No broad provider matrix before the local Codex path works.
